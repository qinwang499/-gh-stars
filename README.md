\# gh-stars



输入一个 GitHub 用户名，输出他所有仓库按 star 排序的表格，并存成 CSV。



\## 我要它能做什么



1\. 命令行传入用户名：`--user octocat`

2\. 拉取该用户所有仓库（要处理分页，一个用户可能有 100+ 仓库）

3\. 每个仓库只保留四个字段：名字、star 数、语言、最后更新时间

4\. 按 star 从高到低排序

5\. 在终端打印成表格

6\. 存成 `stars.csv`，Excel 能直接打开

7\. 出错时给人话，不甩一堆红色 traceback
